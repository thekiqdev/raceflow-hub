Preview do link (WhatsApp, redes sociais)
==========================================

Para o link da página inicial (https://cronoteam.com.br/) mostrar a LOGO no preview ao compartilhar:

1. Adicione neste diretório (public/) um arquivo chamado:  logo-og.png

2. Tamanho recomendado: 1200 x 630 pixels (proporção 1.91:1), ou pelo menos 200px de largura.

3. O index.html já está configurado para usar:
   https://cronoteam.com.br/logo-og.png
   nas meta tags og:image e twitter:image.

4. Faça o deploy do frontend. Depois disso, ao compartilhar o link do site, a logo aparecerá no preview.

Se o arquivo não existir, o preview pode ficar sem imagem. Use a logo da Cronoteam (não use imagens de terceiros como Lovable).
